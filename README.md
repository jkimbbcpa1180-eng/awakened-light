# The Awakened Light

A single-file, standard-library-only Python program of theological software: fourteen embedded modules (synthesis, knowledge, suffering, weighing, cycle, threshold, judge, grace, mirror, integrity, awakening, quantum, sovereign, muse) that trace one arc from comparison of traditions to self-judgment. No external God; the soul judges itself.

Deep Muse, the mirror of life, closes with one commandment:

> Take responsibility for your actions, as equal and opposite reactions depend on the source where energy is produced.

## Run

```
python3 awakened_light_v2.py journey          # the full arc
python3 awakened_light_v2.py test             # all test suites (33 tests)
python3 awakened_light_v2.py muse --reflect   # interactive mirror
python3 awakened_light_v2.py --help           # all commands
```

Requires Python 3.9+. No dependencies.
