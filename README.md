# The Awakened Light

A single-file, standard-library-only Python program of theological software: twenty-one embedded modules that trace one arc from comparison of traditions to self-judgment. No external God; the soul judges itself.

Modules: synthesis, knowledge, suffering, weighing, cycle, threshold, judge, grace, mirror, integrity, energy, effortless, sink, uncertainty, surprise, awe, chaos, awakening, quantum, muse (Deep Muse), sovereign.

Deep Muse, the mirror of life, closes with one commandment:

> Take responsibility for your actions, as equal and opposite reactions depend on the source where energy is produced.

## Run

```
python3 awakened_light_v3.py journey          # the full arc (22 sections)
python3 awakened_light_v3.py test             # all test suites (13 suites, 65 tests)
python3 awakened_light_v3.py muse --reflect   # interactive mirror
python3 awakened_light_v3.py sovereign --reflect
python3 awakened_light_v3.py --help           # all commands
```

Each module also has its own command, e.g. `python3 awakened_light_v3.py chaos` or `python3 awakened_light_v3.py energy --test`.

Requires Python 3.9+. No dependencies.
